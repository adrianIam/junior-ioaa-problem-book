# Content and attribution

This is an independent educational compilation of Junior IOAA problems and
official solutions. The problems, solutions, diagrams, charts, and source-paper
material belong to their respective authors, organisers, and rights holders.

The source archive for this edition is the `Junior Past Papers 2022-2025`
directory of `adrianIam/stars`. Each input is pinned to a revision and Git blob
checksum in `data/papers.json`. That archive currently requires repository
access for downloading the original papers.

The project follows the topic-book approach of `ioanazelko/ioaa-problem-book`.
The build software and layout in this repository were written independently.
Automated transcription assistance was used. Verify transcribed mathematics
against the original papers before using it for teaching or assessment.

No project-wide licence is granted for the third-party source material.
