# 2025 verification record

The 2025 source files contain 16 problems and embedded official solutions. The host is Piatra Neamț, Romania, as printed on the covers. The collection has nine theory entries, three sky-map entries, and four telescope entries. Every entry has a statement and an official solution span.

## Sources and coverage

- `Theory/IOAAJr_2025_Q1-9.pdf` supplies Th.1–Th.9 and their marking schemes. This file contains a cover followed by the printed theoretical-round pages 1–25, whose running headers say “of 26”. The manifest uses zero-based physical PDF page indices.
- `Observation (Sky Map)/IOAAJr_2025_Q10-12.pdf` supplies OM1–OM3, blank maps, and the three marked official map answers.
- `Observation (Telescope)/IOAAJr_2025_Q13-16.pdf` supplies OT1–OT4, the official answers, the marked Lyra image, and all 18 telescope coordinate variants. The original telescope and wall signs were examination apparatus, so the statements carry visible notes identifying this context.

## Source issues retained and flagged

- Th.4(c) uses Earth albedo 0.30 in the official solution although that value is absent from the problem text. A source comment records this dependency.
- Th.5(a) prints a limiting-declination expression without the horizon-dip term. Its numerical result includes both refraction and the dip. A visible note identifies the omitted term, while retaining the official formula and result.
- Th.5(c) prints the magnitude relation with exponential base 2.5. A visible note flags its disagreement with the Pogson law printed earlier in the same solution.
- Th.7(c) says 1.6 cm in prose but uses 1.3 cm in its angular-diameter calculation. Both values are recorded. Its accepted range of 1730–1790 km is printed next to a calculated Earth–Moon distance of 373200 km. The inconsistent range is quoted in a visible note.
- Th.7(f) prints an upper duration of 1 h 75 min beside a 1.6–1.75 h interval. The unusual printed bound is explicitly identified.
